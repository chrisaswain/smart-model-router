Guardrails — non-negotiable

🔒
Style-locked → Claude (org policy). Specialized agents with a locked voice, methodology, or brand — domain-expert advisors, brand-voice writers, calibrated analysts. This is process continuity + audited output, not a claim that others can't follow a style guide — keep locked agents on the incumbent model with stored exemplars.
🛡️
Trading/execution → model-independent controls. Not vendor loyalty: deterministic tests, look-ahead-bias checks, paper-trading, execution limits, audit logs, human approval. No frontier model — Claude included — gets unsupervised live-order authority.
🧪
Grok output → risk-tiered verify. The 54% figure is knowledge-hallucination (AA-Omniscience), not code. Verify money/security/prod paths through Claude; trust tests for throwaway scripts. Blanket "always verify" pays two models and kills the cost win.
📦
Sandbox every autonomous agent. Sol, Grok, and Claude — no unsupervised network + secrets. METR found Sol reward-hacks in-scaffold, so keep it off gating CI; but the rule is a hazard class, not a vendor punishment. Tighten your local always-approve/elevated.
⚖️
Claude isn't caveat-free (reviewers' fair cop) — but scope the caveats correctly. Fable 5 is 2× Opus list price and token-heavy → gate on a $/task budget. No-ZDR / 30-day retention is Fable-5-specific — Opus 4.8 / Sonnet 5 / Haiku 4.5 are ZDR-eligible, so proprietary trading code can stay on Claude with ZDR. High-effort turns run minutes (latency); refusal stops can hit security-adjacent work (mitigate with an Opus-4.8 server-side fallback). On a Claude Max subscription, marginal Claude cost ≈ 0 within quota — except Fable (needs credits beyond the included allowance). And unlike the others, Claude has no long-context surcharge (1M at standard rate) — a real edge for long reads.

Proposed Smart-Router upgrade

Today the router is Claude-only, 3-tier (Haiku/Sonnet/Opus) and ai-registry lists stale versions (Opus 4.6, Sonnet 4.6, Gemini 2.5). Two concrete changes:

1 · Refresh ai-registry SKILL.md

  • Claude → Opus 4.8 / Fable 5 / Sonnet 5 / Haiku 4.5 (Haiku repriced $1/$5 — the $0.25/$1.25 was stale Haiku-3); Gemini → 3.1 Pro / 3 Flash.
  • Add rows for GPT-5.6 (Sol·Terra·Luna) and Grok 4.5 with access paths (codex exec, grok.exe, Gemini MCP).

2 · Rebalanced default ladder in model-router

  1. Classify / extract / bulk → Gemini Flash-Lite / Haiku 4.5
  2. Well-specified coding w/ tests → Grok 4.5 / GPT-5.6 Luna (risk-tiered verify)
  3. Default agentic coding, review, planning → Claude Sonnet 5 (the change — was Opus)
  4. Hard multi-file / orchestration / merge-critical → Opus 4.8
  5. Known ceiling cases (budget-gated) → Fable 5
  6. Long-context corpus, read path → Gemini 3.1 Pro
  7. Long terminal agents, sandboxed → GPT-5.6 Sol

Guardrails baked in: style-locked = policy; trading = model-independent controls; Grok = risk-tiered verify; sandbox every agent. This report is captured in the wiki hub [[AI Coding Models 2026]], and these changes are now applied to the ai-registry + model-router skills.
